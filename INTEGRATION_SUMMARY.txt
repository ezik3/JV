## 🚀 HOW TO USE

### Option 1: Switch via Config File (Recommended)

Edit `src/frontend/config/posConfig.js` line 20:

```javascript
// Current (Enhanced POS - your existing system)
export const ACTIVE_POS_SYSTEM = POS_SYSTEMS.ENHANCED;

// Switch to Nocturne POS
export const ACTIVE_POS_SYSTEM = POS_SYSTEMS.NOCTURNE;
```

### Option 2: Use the CLI Tool

```bash
./switch-pos-system.sh
```

Then select:
1 = Enhanced POS (current)
2 = Nocturne POS (new)
3 = Classic POS

## 🛡️ SAFETY FEATURES

✅ **Zero Breaking Changes**
   - All existing code untouched
   - Enhanced POS remains default
   - Backward compatible

✅ **Automatic Fallback**
   - If Nocturne fails → switches to Enhanced
   - If Enhanced fails → switches to Classic
   - User sees clear error messages

✅ **Error Boundaries**
   - Each POS system isolated
   - Failures don't crash the app
   - Detailed error logging

✅ **Lazy Loading**
   - Components load only when needed
   - Better performance
   - Smaller initial bundle
